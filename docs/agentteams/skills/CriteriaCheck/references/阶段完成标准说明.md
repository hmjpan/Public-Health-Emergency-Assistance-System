# 各阶段完成标准的法规与流程依据

## 启动阶段（responding）完成标准
| 标准 | 依据 |
|------|------|
| 关键小组均已出发或抵达 | 《突发公共卫生事件应急条例》第32条（队伍快速集结出动） |
| 标准物资包均已装车 | 《国家卫生应急队伍管理办法》（2024年版）；GB/T 38567-2020 装备配置指南 |
| 保障车辆均已到位 | 同上，车辆保障属应急队伍基础保障 |

## 现场处置阶段（field）完成标准
| 标准 | 依据 |
|------|------|
| 核心流调/排查完成率100% | CDC 现场调查10步法 |
| 采样送检完毕 | 《传染病信息报告管理规范（2026版）》样本管理要求 |
| 疫点消杀/管控落实 | 《消毒管理办法》、疫点处置规范 |
| 表单/简报影像回传归档 | 《突发公共卫生事件应对法》(2025) 信息报送与档案要求 |

## 设计原则
- 全部标准可量化校验（状态机检查具体状态字段），未达标拒绝推进
- 依据"应急响应闭环"管理要求，每个阶段有明确出口标准
