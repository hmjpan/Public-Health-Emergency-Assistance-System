# 简报/终报/发布稿标准格式规范

## 一、事件简报（处置中）
- 标题：事件名称+日期
- 要素：事件类型、时间、地点、规模（病例数）、处置进展（调查/采样/消杀/救治）、困难与需求
- 提交频率：按阶段节点自动生成（autoMilestone 钩子）

## 二、事件终报（终止后）
- 标题：事件名称+终止评估
- 要素：处置经过、病例转归（治愈/出院/死亡）、溯源结论、防控措施落实、评估建议

## 三、信息发布稿
- 结构：事件概况 → 已采取措施 → 健康提示 → 后续安排
- 口径：按事件类型预填模板（PRESS_TEMPLATES，publishing 路由）
- 审批流：草稿 → 提交审批 → 决策层批准/退回 → 发布（publish:approve/publish:send）

## 发布要求依据
- 《突发公共卫生事件应对法》(2025) 信息发布条款
- 《传染病防治法》(2025修订) 疫情信息公布条款
- 《突发事件应对法》(2024修订) 信息发布与舆论引导要求
