# StaffAssign — 标准编成建议

## 使用场景

根据事件类型和级别，从预案中提取标准编成方案。依据《国家卫生应急队伍管理办法》等国家标准，输出：
1. **工作组构成**（每组名称、最低人数、技能标签）
2. **任务清单**（每组具体任务列表）
3. **法规依据**（每组配置对应的法规条文）
4. **物资包**（需调配的物资清单）
5. **总人数参考**（级别对应总人数要求）

## 法规依据

| 法规 | 关键条款 |
|------|----------|
| 《国家卫生应急队伍管理办法》卫办应急发〔2010〕74号 | 第5-12条：队伍构成、人员要求、装备配置 |
| 《国家突发公共卫生事件应急预案》国办函〔2006〕39号 | 第4.2条：应急队伍组建 |
| GB/T 38567-2020《突发事件卫生应急队伍装备配置指南》 | 第5.2条：各类队伍装备配置 |
| 《卫生应急队伍能力建设指南》（中国CDC） | 队伍能力标准 |

## 标准编成参考

### 国家级卫生应急队伍标准
- **最低总人数**：≥20人（不含后勤保障人员）
- **队长配置**：队长1名（副高以上职称）、副队长2-3名
- **工作组**：7个工作组（流调组、检验组、消杀组、医疗组、监督组、后勤组、车辆组）
- 来源：《国家卫生应急队伍管理办法》第5条

### 各级别人员倍率
| 级别 | 倍率 | 总人数参考 | 附加组 |
|------|------|-----------|--------|
| I级（特别重大） | ×2.5 | ≥50人 | +专家组 |
| II级（重大） | ×2.0 | ≥40人 | +专家组 |
| III级（较大） | ×1.5 | ≥30人 | — |
| IV级（一般） | ×1.0 | ≥20人 | — |

## Guardrail（约束边界）

### 确定性约束（D1级）
1. **数据查询**：编成方案来自 composition.json 规则表，非LLM生成
2. **倍率确定性**：级别对应倍率固定（I级×2.5/II级×2.0/III级×1.5/IV级×1.0）
3. **人数下限**：每组 minCount 不低于基础值 baseCount

### 业务约束
4. **仅建议**：输出编成建议，人员指派由指挥员确认（Skill 不自动分配人员）
5. **法规引用**：每组配置附对应法规依据（role_ref），确保编成有法可依
6. **规则版本存证**：每次输出携带 ruleVersion，确保审计可追溯

### 容错约束
7. **未知类型处理**：无该类型编成时返回 `ok: false` + 错误信息
8. **级别缺失处理**：无该级别倍率时默认使用 1.0

## 执行证据链

```
输入(typeKey, level) → 查询 composition.json[typeKey]
                       → 获取基础工作组(groups) + 级别倍率(levelAdj)
                       → 每组 minCount = max(base, ceil(base × multiplier))
                       → 附加组(如专家组) × multiplier
                       → 附加物资包 + 法规依据
                       → 写入 rule_results 存证
```

**证据要素**：
- `provenance`: 规则表来源（composition.json + 版本号）
- `groups_count`: 输出工作组数量
- `total_min_count`: 调整后总最低人数
- `methodology`: 规则表查询 + 级别倍率调整

## 调用条件

- Commander Agent 一键启动时调用（获取编成方案）
- Dispatch Agent 接收后执行人员匹配

## 依赖工具/系统

- `composition.json` 规则表（事件类型×级别的编成标准）
- 通讯录服务（用于人员匹配，由 Dispatch Agent 调用）

## 失败处理

1. **未知事件类型** → 返回 `ok: false` + '无该类型标准编成: {typeKey}'
2. **未知级别** → 使用 multiplier=1.0（最小编成）
3. **规则表缺失** → 系统启动自检告警

## 安全边界

- 编成为预案既定（数据查询），人员指派由人决定
- 结果含 `ruleVersion` + `evidence` 存证
- 每组配置附法规依据（role_ref），可审计

## 复用价值

⭐ 高。任何需要"按场景×级别→团队编成"的场景均可复用。典型场景：项目团队组建、应急值班编排、活动保障人员配置。规则表可替换。
