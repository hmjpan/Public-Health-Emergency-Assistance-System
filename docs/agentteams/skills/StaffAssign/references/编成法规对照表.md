# 工作组编成与法规条文对照表

| 工作组 | 职责 | 法规依据 |
|--------|------|----------|
| 流调组 | 个案调查、密接排查、传播链分析 | 《传染病防治法》(2025修订) 疫情调查条款 |
| 采样组 | 生物/环境/食品样本采集 | 《传染病信息报告管理规范（2026版）》 |
| 检验组 | 病原/毒物检测 | 《实验室生物安全条例》 |
| 消杀组 | 疫点终末消杀 | 《消毒管理办法》 |
| 管控组 | 风险点位封控管理 | 《突发事件应对法》(2024修订) |
| 医疗救治组 | 病例救治与转诊 | 《传染病防治法》(2025修订) 医疗救治条款 |
| 物资保障组 | 物资储备与调拨 | 《国家卫生应急队伍管理办法》(2024年版) |
| 车辆保障组 | 转运与后勤保障 | 同上 |

## 编成规则
- 不同事件类型/级别对应不同工作组组合（由 rules/composition.json 决定）
- 队伍能力要求依据《国家卫生应急队伍管理办法》（2024年版，替代2010年版）
- 装备配置依据 GB/T 38567-2020《突发事件卫生应急队伍装备配置指南》
