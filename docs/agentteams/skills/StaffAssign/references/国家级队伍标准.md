# 《国家卫生应急队伍管理办法》（2024年版）要点摘录

## 队伍建设标准
- 2024年3月印发，替代2010年试行版
- 明确国家级卫生应急队伍分类（传染病防控、紧急医学救援、核辐射、化学中毒等）
- 队伍构成：专业技术人员为主体，含管理、后勤保障人员

## 装备与物资要求
- 装备配置遵循 GB/T 38567-2020《突发事件卫生应急队伍装备配置指南》
- 标准物资包按事件类型差异化配置（本系统 eventTypes.js 中 materialPacks 对应实现）

## 演练与培训要求
- 队伍须定期开展应急演练（本系统"模拟演练模式"直接支撑该要求）
- 演练评估结果反馈队伍建设（对应"复盘→知识库→Skill迭代"机制）

## 意义
- 本系统 StaffAssign/编成、物资包、演练模式均以此办法为制度依据
