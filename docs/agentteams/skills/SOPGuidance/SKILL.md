# SOPGuidance — 岗位SOP指引

## 使用场景

现场处置人员需要具体操作指导时，系统根据：
1. **事件类型**（INF/FOOD/ENV/POISON/UNK）
2. **当前阶段**（现场调查/控制措施/采样检测/医疗救治/善后）
3. **所属工作组**（流调组/采样组/消杀组/管控组/医疗组等）

从知识库匹配相关SOP + CDC标准调查步骤，通过LLM生成**定制化操作指导**，含注意事项、常见错误、关键要点。

## CDC 现场疫情调查 10 步法（标准参考）

依据美国CDC《Principles of Epidemiology in Public Health Practice》第三版，结合中国CDC现场调查实践：

| 步骤 | 名称 | 关键动作 | 适用阶段 |
|------|------|----------|----------|
| 1 | 准备现场工作 | 组建团队、准备装备、了解背景 | 响应启动 |
| 2 | 确认暴发存在 | 核实病例数是否超过基线水平 | 现场调查初期 |
| 3 | 验证诊断 | 确认实验室检测结果、排除误诊 | 采样检测 |
| 4 | 定义病例并开展搜索 | 制定病例定义（疑似/临床诊断/确诊）、主动搜索 | 现场调查 |
| 5 | 描述性流行病学（时间/地点/人群） | 绘制流行曲线、制作病例分布地图、描述人群特征 | 现场调查 |
| 6 | 形成假设 | 基于三间分布提出暴露来源假设 | 分析研判 |
| 7 | 评估假设 | 病例对照研究/队列研究验证假设 | 分析研判 |
| 8 | 完善假设并补充研究 | 环境采样、实验室验证 | 深入调查 |
| 9 | 实施控制措施 | 隔离/消杀/管控/健康教育 | 控制措施 |
| 10 | 沟通调查结果 | 撰写调查报告、向相关方通报 | 善后总结 |

## 各类事件现场 SOP 要点

### 传染病疫情（INF）现场 SOP
- **流调组**：个案调查→密接排查→传播链分析→发病曲线绘制
- **采样组**：患者标本→环境标本→快速检测→送检确认
- **消杀组**：疫点消杀→终末消毒→病媒控制
- **管控组**：风险点位管控→密接管理→隔离点巡查
- **医疗组**：病例救治→院感防控→重症监护

### 食物中毒（FOOD）现场 SOP
- **流调组**：就餐史调查→共同暴露餐次分析→食谱调查→病例对照研究
- **采样组**：食品留样采集→生物样本→环境涂抹→快速检测
- **管控组**：涉事单位管控→可疑食品封存→溯源调查
- **医疗组**：患者救治→对症支持→重症监护

### 环境污染（ENV）现场 SOP
- **采样组**：环境介质采样(水/气/土)→污染物定性→浓度监测
- **流调组**：暴露人群筛查→剂量-反应分析→健康影响评估
- **消杀组**：人员洗消→污染区域洗消→阻断扩散
- **管控组**：污染源封控→人员疏散管控→交通管制
- **医疗组**：暴露者检查→中毒救治→健康监测

### 职业中毒（POISON）现场 SOP
- **医疗组**：现场急救→解毒治疗→重症监护
- **采样组**：毒物定性定量→空气浓度→生物样本
- **管控组**：作业场所封控→人员疏散→通风排毒
- **流调组**：中毒原因调查→暴露评估→防护漏洞排查

## Guardrail（约束边界）

### SOP生成约束
1. **知识库优先**：优先使用知识库中已有的SOP，LLM用于定制化和补充
2. **CDC标准参考**：生成的SOP应参考CDC 10步法框架，不凭空编造步骤
3. **实操可执行**：每步操作必须具体可执行，不允许"做好防护"等模糊表述
4. **分组合理**：SOP步骤必须按工作组分组，不允许跨组混合

### 安全约束
5. **不含处方建议**：医疗救治SOP不含具体药物处方，仅描述治疗原则
6. **不涉及个人信息**：SOP中不涉及具体患者个人信息
7. **标注来源**：SOP步骤标注来源（知识库SOP / 任务包标准步骤 / LLM建议）

### LLM约束
8. **JSON输出强制**：LLM输出必须为合法JSON，解析失败时降级为任务包步骤
9. **温度控制**：temperature=0.3（降低随机性，提高一致性）
10. **降级透明**：LLM不可用时明确标记 llm_used=false

## 执行证据链

```
输入(typeKey, stage, group, taskTitle, context)
  ├── 知识库匹配: knowledge.json 中 SOP 条目(typeKey + stage)
  ├── 任务包解析: eventTypes.js 中对应任务(typeKey + group)
  ├── CDC步骤映射: 根据stage映射到CDC 10步法的对应步骤
  ├── LLM生成: 综合以上信息 → 定制化操作指导
  └── 输出: sop[] + precautions[] + commonMistakes[] + keyPoints + evidence
```

**证据要素**：
- `provenance`: 知识库 + LLM
- `sop_count`: 匹配到的知识库SOP数量
- `task_count`: 匹配到的任务包任务数量
- `cdc_step_ref`: 对应的CDC 10步法步骤编号
- `methodology`: 知识库匹配 + 任务包 + LLM定制化

## 调用条件

Field Agent 分发任务或现场人员请求指引时调用。

## 依赖工具/系统

- `knowledge.json` 知识库中的 SOP 条目
- `eventTypes.js` 任务包配置
- LLM 用于生成定制化指导文本

## 失败处理

1. **LLM 不可用** → 使用任务包中的标准步骤作为 SOP
2. **无匹配SOP** → 返回通用操作建议（基于CDC框架的通用步骤）
3. **无匹配任务** → 返回知识库SOP（如有）+ LLM生成的通用建议
4. **LLM 输出解析失败** → 降级使用任务包标准步骤

## 安全边界

- SOP指引需经现场指挥员确认后执行
- 不含具体药物处方
- 结果含 `evidence` 存证
- LLM调用记录写入 rule_results
