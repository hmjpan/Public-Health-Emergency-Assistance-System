# 《传染病信息报告管理规范（2026版）》五分类体系摘录

## 事件分类（对应 Skill 五分类）
| 分类 | 类型Key | 报告要求 |
|------|---------|----------|
| 传染病疫情 | INF | 甲类2小时、乙丙类24小时内网络直报 |
| 食源性疾病/食物中毒 | FOOD | 确诊食物中毒事件立即报告 |
| 环境污染健康事件 | ENV | 事件发生后2小时内初报 |
| 急性职业中毒 | POISON | 中毒事件立即报告并启动应急救援 |
| 原因不明群体性疾病 | UNK | 无法归因的聚集性事件按最严重可能性处置（最大风险原则） |

## 分类判定要点（《国家突发公共卫生事件相关信息报告管理工作规范》）
1. 依据暴露史/场所/症状组合判定，而非单一症状
2. 同一事件只归属一个主分类（按最贴近暴露途径）
3. 无法确定时按最大风险原则归类并人工复核
