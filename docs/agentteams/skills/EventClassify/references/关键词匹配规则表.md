# eventTypes.js 关键词匹配规则表

## 匹配优先级（自上而下，先命中先返回）
| 优先级 | 规则 | 关键词示例 |
|--------|------|------------|
| 1 | 强传染病命名信号 | 诺如、流感、新冠、霍乱、鼠疫、麻疹、手足口、水痘、登革、疟疾、结核、炭疽、乙肝、丙肝、艾滋、狂犬 |
| 2 | 食源信号 | 食源、食物中毒、食品安全、聚餐、宴席、食堂、外卖、餐饮、就餐史、同餐、午餐后、晚餐后、早餐后、呕吐腹泻、腹泻呕吐、恶心呕吐 |
| 3 | 环境/化学污染 | 化学、污染、环境、毒气、泄漏、辐射、异味 |
| 4 | 职业中毒 | 职业中毒、有限空间、农药中毒、气体中毒、中毒事件 |
| 5 | 原因不明 | 不明、待查、群体性、聚集性（非"疫情"语境） |
| 6 | 一般传染病表述 | 传染病、疫情、病毒、发热、咳嗽、聚集性疫情 |
| 兜底 | 无匹配 | strict模式返回null（双证据"无证据"分支→UNK低置信度） |

## 设计说明
- 法定传染病命名优先于场所/症状词，避免"诺如在学校食堂暴发"误判为食源
- strict=true 供 EventClassify 双证据验证使用，无匹配时走"no_evidence→UNK(0.3)"分支并建议人工复核
- 规则表与 LLM 语义分类交叉校验，一致则置信度+0.05
