# 复盘报告标准结构

## 报告章节
1. **事件概要**：类型、级别、时间线、波及范围
2. **处置过程回顾**：启动→出动→现场→终止各环节执行情况
3. **量化统计**：
   - 任务完成率（done/total、受阻数）
   - 通知确认率（acked/total、升级数）
   - 出动人数、病例数、Agent 协同会话数
   - 事件总时长（小时）
4. **问题清单**：按严重程度排序（来源：处置过程问题记录）
5. **经验教训**：可供复盘的结论
6. **整改建议**：转化为整改台账（rectifications），明确责任人/时限
7. **知识沉淀建议**：可回流知识库的条目

## 依据
- 《国家突发公共卫生事件应急预案》第5.3条：事件处置结束后的总结评估要求
- 《突发公共卫生事件应对法》(2025)：复盘评估与持续改进的法律要求
