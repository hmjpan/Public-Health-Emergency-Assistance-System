# 知识库四类体系与匹配加权说明

## 知识条目四分类
| 分类 kind | 内容 | 来源 |
|-----------|------|------|
| plan 预案 | 分级预案/处置流程 | 各类卫生应急预案（国办函〔2006〕39号体系） |
| sop 操作指引 | 岗位SOP/标准操作程序 | CDC 现场调查10步法等 |
| measure 处置措施 | 防控措施条目 | 历次事件复盘沉淀 + 技术方案 |
| case 案例 | 历史案例 | 复盘知识回流 |

## 匹配加权（PlanMatch Skill）
- 类型匹配（typeKey）：权重最高
- 级别匹配（level）：次之
- 阶段匹配（stage）：第三
- 加权求和后按得分排序，返回 topN

## 知识回流闭环
复盘 → 提炼措施/教训 → 沉淀知识库 → PlanMatch 检索命中 → 指导下次处置
（对应"每次可改进"创新点）
