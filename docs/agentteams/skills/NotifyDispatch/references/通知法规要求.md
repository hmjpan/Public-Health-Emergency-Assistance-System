# 通知时限与强制反馈的法规依据

## 通知/报告时限
| 环节 | 时限 | 法规依据 |
|------|------|----------|
| 突发公共卫生事件初报 | 2小时 | 《突发公共卫生事件应对法》(2025)；《应急条例》第19条 |
| 甲类传染病报告 | 2小时 | 《传染病信息报告管理规范（2026版）》 |
| 乙丙类传染病报告 | 24小时 | 同上 |
| 应急响应启动确认 | 1小时内 | 《国家突发公共卫生事件应急预案》第3.2条 |

## 强制反馈（确认闭环）要求
- 《突发公共卫生事件应急条例》第32条：接到命令的单位和个人必须立即执行，不得拒绝、拖延
- 通知须可追溯：发送→确认→执行→反馈全程留痕
- 超时未确认需升级：本系统实现"5分钟确认时限+超时自动升频并通知上级"

## 多通道要求
- 语音（最高优先级）/短信（文字留痕）/APP推送（即时触达）三通道并行
- 通道日志留存（channellogs），保证"通知了谁、何时、什么内容、是否确认"全程可查
