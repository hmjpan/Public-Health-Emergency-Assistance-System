# CaseTrack — 病例全流程分析

## 使用场景

跟踪病例全生命周期，基于病例数据进行流行病学分析：
1. **统计描述**：病例数、状态分布、严重程度分布
2. **流行病学指标**：罹患率、病死率(CFR)、重症比例
3. **趋势分析**：发病时间趋势（上升/平稳/下降）、流行曲线解读
4. **预警建议**：基于指标阈值自动预警
5. **风险因素**：识别高风险人群/场所/行为

## 流行病学分析框架

### 病例状态流转
```
暴露 → 潜伏期 → 发病 → 就诊 → 报告 → 隔离/住院 → 治疗 → 转归(治愈/死亡/后遗症)
```

### 关键流行病学指标
| 指标 | 计算公式 | 预警阈值 | 法规依据 |
|------|----------|----------|----------|
| **罹患率(Attack Rate)** | 发病人数/暴露人口×100% | 视病种而定 | CDC标准 |
| **病死率(CFR)** | 死亡数/确诊病例数×100% | >1%需关注 | 《传染病防治法》 |
| **重症比例** | 重症数/确诊数×100% | >10%需关注 | 临床标准 |
| **续发率(SAR)** | 密接中发病数/密接总数×100% | 视病种 | CDC标准 |

### 病例严重程度分级
| 分级 | 临床特征 | 处置要求 |
|------|----------|----------|
| **轻症** | 症状轻微，无需住院 | 居家隔离+对症治疗 |
| **普通型** | 有明显症状，需医学观察 | 集中隔离/住院观察 |
| **重症** | 出现并发症/器官功能损害 | 住院治疗+重症监护 |
| **危重症** | 多器官功能衰竭/生命体征不稳 | ICU+生命支持 |

### 流行曲线解读
| 曲线类型 | 特征 | 提示 |
|----------|------|------|
| **点源暴露** | 病例集中出现于一个潜伏期内 | 共同暴露源（如食物中毒） |
| **连续暴露** | 病例持续出现，跨度超过一个潜伏期 | 持续暴露源（如水源污染） |
| **人传人** | 出现多个发病高峰，间隔约一个潜伏期 | 人际传播（如呼吸道传染病） |
| **混合** | 既有集中爆发又持续散发 | 点源暴露+人传人 |

## Guardrail（约束边界）

### 统计约束
1. **确定性计算**：罹患率/病死率/重症比例等指标由系统确定性计算，不经LLM
2. **分母缺失处理**：暴露人口未知时，罹患率显示"暂无数据"而非估算
3. **零分母保护**：确诊数为0时，病死率/重症比例显示"N/A"

### 临床约束
4. **不含具体处方**：建议中不含具体药物名称和剂量，仅描述治疗原则
5. **转归确认**：病例"治愈"需有明确出院记录，不可自动判定
6. **严重程度分级**：严格使用轻症/普通型/重症/危重症四级分类

### LLM约束
7. **趋势分析辅助**：LLM用于趋势解读和建议生成，不用于指标计算
8. **降级透明**：LLM不可用时返回统计摘要 + "待分析"标记
9. **不替代临床判断**：所有分析结果标注"仅建议，诊疗决策由医疗人员判断"

### 隐私约束
10. **匿名化**：输出不含患者姓名、身份证等个人信息
11. **最小必要**：仅分析事件相关病例，不跨事件关联

## 执行证据链

```
输入(eventId, cases[])
  ├── 确定性统计: 病例数/状态分布/严重程度分布/流行病学指标
  ├── 指标阈值比对: 重症比例>10%? 病死率>1%? → 触发预警
  ├── 时间趋势: 按发病日期统计每日新增 → 判断上升/平稳/下降
  ├── LLM分析: 综合以上 → 趋势解读 + 风险因素 + 建议
  └── 输出: stats + epi_indicators + alerts + suggestions + evidence
```

**证据要素**：
- `provenance`: cases 数据表 + LLM
- `total_cases`: 分析病例总数
- `indicators_calculated`: 计算了多少项指标
- `methodology`: 描述性流行病学 + LLM趋势分析

## 调用条件

Medical Agent 在病例数据更新时调用（新增病例/状态变更/转归更新）。

## 依赖工具/系统

- `cases` 数据表（病例全流程数据）
- LLM 用于趋势分析和建议生成

## 失败处理

1. **LLM 不可用** → 返回统计摘要 + epi_indicators + "趋势待分析"
2. **无病例数据** → 返回空统计 + "暂无病例数据"
3. **病例数据不完整** → 计算可用指标 + missing_evidence 标注缺失项

## 安全边界

- 分析结果仅建议，诊疗决策由医疗人员判断
- 输出匿名化，不含患者个人隐私信息
- 结果含 `evidence` 存证
