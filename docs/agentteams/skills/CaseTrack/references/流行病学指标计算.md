# 流行病学指标计算方法

## 1. 罹患率（Attack Rate）
- 定义：观察期内特定人群中发病（或出现特定结局）的比例
- 公式：罹患率 = 发病人数 / 暴露人口数 × 100%
- 适用：食源性疾病共同暴露餐次分析（按餐次分组计算，排序后锁定最可疑餐次）

## 2. 病死率（Case Fatality Rate）
- 公式：病死率 = 因该病死亡人数 / 确诊(报告)病例数 × 100%
- 分级参考：病死率高低是事件定级（GradeEvaluate）的重要输入之一

## 3. 重症比例
- 公式：重症比例 = 重症(含危重)病例数 / 在治病例数 × 100%
- 用途：评估医疗资源需求（ICU床位、呼吸机等），触发资源预警

## 4. 潜伏期与流行曲线
- 点源暴露：单峰曲线，发病时间集中在暴露后一个潜伏期内
- 人传人：逐波上升曲线，周期接近潜伏期

## 依据
- 《突发公共卫生事件流行病学调查规范》及 CDC 现场调查方法学（10步法第5步"描述性流行病学"）
