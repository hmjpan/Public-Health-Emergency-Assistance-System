# 流行曲线（Epidemic Curve）解读

## 曲线类型与暴露模式
| 类型 | 特征 | 推断 |
|------|------|------|
| 点源暴露（Point Source） | 单峰，骤升骤降 | 共同暴露（食物/水/污染源），一次事件 |
| 连续暴露（Continuous Source） | 平台期或持续上升 | 污染持续存在（水源污染/持续污染食品） |
| 人传人（Propagated） | 逐波上升，间隔≈潜伏期 | 传染病人际传播 |
| 混合型 | 先点源后逐波 | 点源暴发后继发人传人 |

## 三间分布（时间/地点/人群）分析
- 时间：发病曲线 + 潜伏期反推可疑暴露时间窗
- 地点：病例地图，判定聚集区域与共同暴露场所
- 人群：按年龄/性别/工种/就餐史分组计算罹患率

## 用途
- 密接追踪与暴露餐次调查的排序依据（按罹患率降序）
- 病因线索收敛：锁定可疑餐次/污染源

## 依据
- CDC 现场疫情调查10步法（第5步描述性流行病学、第7步评估假设）
