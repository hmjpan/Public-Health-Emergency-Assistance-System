# 病例严重程度分级标准

## 传染病/食源病例
| 分级 | 标准 | 处置 |
|------|------|------|
| 轻症 mild | 症状轻微，无需住院或门诊对症即可 | 居家/门诊随访 |
| 普通 moderate | 需住院治疗，无器官功能损害 | 定点医院普通病房 |
| 重症 severe | 出现器官功能障碍或合并基础疾病加重 | ICU/加强病房 |
| 危重 critical | 呼吸衰竭/休克/多器官功能衰竭 | 立即ICU，多学科会诊 |

## 判定要素
- 体温、氧合（SpO₂）、血压、意识状态
- 实验室指标（血常规、炎症指标、生化）
- 影像学（胸部CT等）

## 用途
- 病例跟踪 Skill 的严重程度统计与"异常病例"预警（转重症/危重即标红）
- 医疗资源动态调配依据

## 依据
- 《传染病防治法》(2025修订) 医疗救治相关条款
- 各病种诊疗方案（如新冠、流感诊疗方案）分级标准
